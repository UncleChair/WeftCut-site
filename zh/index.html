第 01 场真正的分野

不是外挂，是内建。

多数剪辑器把 AI 当作一个附加功能。WeftCut 通过标准 MCP 把整个编辑器开放给你的 agent——你能做的，它都能做。

  • 接入

    设置 → Agent，复制，粘贴——Claude、Cursor 或任意 MCP 客户端一分钟接入。全程本地，不上传任何内容。

  • 手艺

    完整的剪辑词汇都摆在桌面上：修剪、切分、转场、关键帧、特效、字幕、标记、撤销。

  • 掌控

    改动实时落地，并置于检查点之下——随时查看变更流，或撤销并重新接管。

  • 洞察

    可选的本地分析让 agent 先看清再下刀：镜头、静音段、转写、画面描述。

第 03 场属于人的那一刀

人拥有完整控制。agent 拥有完整权限。

你保有一台专业桌面剪辑器该有的精度与控制。你的 agent 拿到同一套工具，而每一次改动都清晰地留在时间线上。

关键帧与曲线

彩蛋一些细节

常见问题。

  • WeftCut 免费吗？

    免费——基于 MIT 许可开源。随附的 FFmpeg 遵循其自身的 LGPL/GPL 条款。

  • 我可以接入哪些 agent？

    任意 MCP 客户端——Claude Desktop、Cursor、Codex，或你自己写的。从「设置 → Agent」复制一段配置，粘进你的客户端，agent 就能和你并肩剪辑。WeftCut 不内置任何 AI 模型——智能来自你接入的 agent。

  • 不接 agent 也能用吗？

    能——它本身就是一台完整的剪辑器：A/B 卷时间线、关键帧、特效、字幕、Motif、音频混音，以及最高 10-bit AV1 与 ProRes 的导出。

  • AI 在哪里运行？

    在你的 agent 里，不在应用里——WeftCut 不附带任何模型。转写、画面描述这类可选分析在你本机上运行。

  • 支持哪些平台？

    macOS、Windows 和 Linux——同一个桌面应用，各平台功能一致。

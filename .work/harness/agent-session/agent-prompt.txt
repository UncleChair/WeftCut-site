## MCP surface notes — follow these exactly, they prevent rejected calls

- CRITICAL — nested fields are real JSON objects, NOT quoted strings. The fields `interp` (set_keyframe), `props` (add_motif), and `patch` (update_effect / update_layer / update_layer_params) are loosely typed in the schema, and it is tempting to pass them as a JSON-encoded string. The server rejects that with "must be a JSON object". The value must start with `{`, not with `"`. Literal examples of CORRECT full argument payloads:
  - `{"motif_id":"lower-third","t_start_us":800000,"t_end_us":5300000,"props":{"title":"Aurora Ridge","subtitle":"Cut by an agent over MCP","accent":"#6696E6"}}`
  - `{"layer_id":"<id>","param_key":"opacity","t_us":1500000,"value":1,"interp":{"kind":"EaseOut"}}`
  - `{"layer_id":"<id>","effect_id":"<id>","patch":{"params":{"strength":{"mode":"Static","value":4}}}}`
  If you ever see "must be a JSON object" / "not an object", your value was a quoted string — resend the SAME call with the quotes removed, nothing else changed.
- Effects: `add_effect {layer_id, kind: "blur"}` creates the effect with NO params. Then set its strength with `update_effect` using the patch shape above (blur's only param is `strength`; ~3–5 is gentle). Do not keyframe effect params in this session.
- Placement discipline: all three acts go on the A roll track, back to back; embers goes on the B roll track only. If a placement is rejected with "layer overlap", NEVER resend the same call — something already occupies that span (remember each video clip lands with its paired audio layer on the same track). Re-plan: pick the other allowed track or shift the time window, once.
- `detect_silences` needs the clip's waveform, which generates in the background after import. If it answers "waveform not generated yet", carry on with other edits and retry it a bit later — don't spin on it.
- Layer opacity/scale keyframes: `param_key` is just `"opacity"` / `"scale_x"` / `"scale_y"`; `t_us` is timeline-absolute.
